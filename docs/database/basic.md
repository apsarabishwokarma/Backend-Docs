## DATABASE

A database is an organized collection of data stored electronically in a computer system.

## Core Components

- Data:
  The raw, structured, or unstructured information stored within the system.
- DBMS (Database Management System:
- The software program that acts as an interface between the database and its users or programs, letting people create, update, and manage data.
- Query Language: A specialized programming language—like Structured Query Language (SQL)—used to query, search, and change the data.

## Common Types

- Relational Databases (RDBMS): Store data in structured tables with rows and columns, linked by specific keys (e.g., MySQL, PostgreSQL).
- NoSQL Databases: Designed for unstructured or semi-structured data, using flexible formats like documents or key-value pairs (e.g., MongoDB).
- Cloud Databases: Hosted on cloud computing platforms, allowing remote scaling and access

## ACID Properties

ACID stands for Atomicity, Consistency, Isolation, and Durability

- Atomicity: Ensures transactions complete fully or not at all.
- Consistency: Ensures the database moves from one valid state to another.
- Isolation: Ensures that multiple transactions can happen at the same time without affecting each other.
- Durability: Saves changes permanently after completion.
